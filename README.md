# 🍔 Burgers & World Cup

Сайт-приглашение на бургер-пати с просмотром ЧМ-2026. Гости собирают себе бургер,
а ты получаешь все заказы строками в свою приватную Google-таблицу.

**Ссылка для друзей:** https://trofimoffpetr-hash.github.io/burger-worldcup/

---

## Как это устроено

- Статический сайт (`index.html` + `styles.css` + `app.js`) лежит на **GitHub Pages**.
- При нажатии «Сделать заказ» браузер отправляет заказ в **Google Apps Script**,
  который дописывает строку в твою **Google-таблицу**.
- Никаких токенов/паролей в коде страницы нет — публичен только URL веб-приложения,
  который умеет лишь добавлять строки в таблицу.

---

## Настройка приёма заказов (~10 минут, один раз)

1. Создай пустую **Google-таблицу** на https://sheets.new (она приватная — видишь только ты).
2. В таблице: меню **Расширения → Apps Script**.
3. Удали содержимое и вставь весь код из файла [`apps-script.gs`](apps-script.gs). Сохрани (Ctrl+S).
4. Нажми **Развернуть → Новое развёртывание**.
   - Тип: **Веб-приложение** (Web app).
   - «Выполнять от имени»: **Я (твой аккаунт)**.
   - «У кого есть доступ»: **Все** (Anyone).
   - Нажми **Развернуть**, при запросе — разреши доступ к своему аккаунту.
5. Скопируй **URL веб-приложения** (вида `https://script.google.com/macros/s/AKfy.../exec`).
6. Открой файл [`config.js`](config.js) и вставь этот URL:
   ```js
   const ORDERS_ENDPOINT = "https://script.google.com/macros/s/AKfy.../exec";
   ```
7. Закоммить и запушь изменение (см. ниже). Готово — заказы начнут падать в таблицу.

> Пока `ORDERS_ENDPOINT` пуст, сайт работает в **демо-режиме**: показывает анимацию
> и сводку заказа, но никуда его не отправляет.

### Проверить, что заказы приходят
Оформи тестовый заказ на сайте и обнови Google-таблицу — должна появиться новая строка
со временем, именем и составом бургера.

## Публикация / обновление сайта

Репозиторий уже на GitHub и опубликован через GitHub Pages. Чтобы выложить изменения:

```bash
cd burger-worldcup
git add .
git commit -m "update"
git push
```
Через 1–2 минуты обновление появится по ссылке выше.

## Структура файлов

| Файл             | Назначение                                         |
|------------------|----------------------------------------------------|
| `index.html`     | Разметка страницы                                  |
| `styles.css`     | Стили (тёмная тема, акценты горчица/кетчуп)         |
| `app.js`         | Логика формы, отправка заказа, анимация            |
| `config.js`      | URL приёмника заказов (`ORDERS_ENDPOINT`)          |
| `apps-script.gs` | Код Google Apps Script для копирования в редактор  |
